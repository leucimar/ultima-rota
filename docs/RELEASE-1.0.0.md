# Última Rota v1.0.0

Distribuição Windows 64 bits da versão final da develop, publicada em 14/11/2026.

## O que está incluído

- Floresta e cidade com a arte renovada dos cenários, personagens e inimigos.
- Combate com os projéteis atualizados, chefes, progressão por zonas e objetivos da expedição.
- Melhorias e inventário persistentes, com início sem recursos ou aprimoramentos comprados.
- Menu, Safe Zone, dois mapas e runtime completo para jogar sem instalar a Unity.

## Como iniciar

1. Baixe [UltimaRota-Windows-x64.zip](https://github.com/leucimar/ultima-rota/releases/latest/download/UltimaRota-Windows-x64.zip).
2. Extraia o ZIP inteiro para uma pasta.
3. Abra **UltimaRota.exe**, mantendo os dados, as pastas de runtime e as DLLs junto dele.

WASD para mover, mouse para mirar, clique esquerdo para atirar, E para interagir e ESC para pausar.

No início: vida 100, saldos zerados, níveis básicos, pistola equipada e fuzil bloqueado. Os bônus de testes anteriores não são importados para o perfil de distribuição. O progresso conquistado pelo jogador é salvo para as próximas partidas.
