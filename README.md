# Última Rota

Página pública e distribuição Windows do survival shooter 2D desenvolvido em Unity para Programação para Jogos, Ciência da Computação — UNIPAC.

**Jogue:** https://leucimar.github.io/ultima-rota/

**Download Windows:** https://github.com/leucimar/ultima-rota/releases/latest/download/UltimaRota-Windows-x64.zip

## Manutenção

A publicação usa a branch `feature/Ultima_Rota_Page` e a pasta `/docs`. Edite os arquivos nessa pasta e envie suas alterações. O GitHub Pages publica automaticamente. Veja [instruções de edição, build e atualização](docs/PUBLICACAO.md).

Este repositório contém somente o site e a distribuição em Releases. O código-fonte do jogo continua no repositório privado da equipe. Não envie o histórico, Assets ou scripts C# do projeto para cá.
